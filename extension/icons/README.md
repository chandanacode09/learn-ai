# Extension Icons

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

For now, you can create simple placeholder icons or use an icon generator.

## Quick Icon Creation

You can use online tools like:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

Or create them programmatically using Python PIL or similar tools.

## Recommended Design

- Use the 🧠 brain emoji as the base
- Color scheme: Purple to blue gradient (#667eea to #764ba2)
- Simple, recognizable design
