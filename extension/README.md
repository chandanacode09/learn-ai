# AI Content Explainer - Chrome Extension

One-click explanations for any web page.

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select the `extension` directory

## Usage

1. Navigate to any technical article or blog post
2. Click the extension icon in your toolbar
3. Select your desired explanation level and mode
4. Click "Explain This Page"
5. View the instant summary and key takeaways

## Features

- **Multiple Explanation Levels**: From ELI5 to Expert
- **Different Modes**: Personal, Educational, or Professional
- **Instant Summaries**: Get the gist in seconds
- **Key Takeaways**: Bullet-point highlights
- **View Full**: Open detailed explanation in web app

## Requirements

- Chrome browser (or Chromium-based browser)
- Backend API running on `http://localhost:8000`
- Frontend web app running on `http://localhost:3000` (optional)
